# `sklearn_mastery.config`

Pydantic settings (overridable with `SKLEARN_MASTERY_*` environment
variables or a `.env` file) and library-style logging. `settings`,
`ModelDefaults`, `setup_logging` and `get_logger` are also re-exported from
the top-level `sklearn_mastery` package.
