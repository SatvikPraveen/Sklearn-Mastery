# Citing

If `sklearn-mastery` contributes to your research, please cite the software.
The repository ships a `CITATION.cff` file, which GitHub renders as a
"Cite this repository" button with APA and BibTeX output.

## BibTeX

```bibtex
@software{praveen2026sklearnmastery,
  author  = {Praveen, Satvik},
  title   = {sklearn-mastery: a research-grade toolkit for reproducible scikit-learn experiments},
  version = {2.0.0},
  year    = {2026},
  license = {MIT},
  url     = {https://github.com/SatvikPraveen/Sklearn-Mastery}
}
```

## APA

Praveen, S. (2026). *sklearn-mastery: a research-grade toolkit for
reproducible scikit-learn experiments* (Version 2.0.0) [Computer software].
https://github.com/SatvikPraveen/Sklearn-Mastery

## Methods to cite alongside

When you report results produced with the research layer, cite the
underlying procedures as well:

| Procedure | Reference |
|---|---|
| Friedman test, Nemenyi post-hoc, Wilcoxon-Holm, critical-difference diagrams | Demšar, J. (2006). Statistical comparisons of classifiers over multiple data sets. *JMLR*, 7, 1-30. |
| Iman-Davenport correction | Iman, R. L., & Davenport, J. M. (1980). Approximations of the critical region of the Friedman statistic. *Communications in Statistics*, 9(6), 571-595. |
| Corrected resampled *t*-test | Nadeau, C., & Bengio, Y. (2003). Inference for the generalization error. *Machine Learning*, 52, 239-281. |
| Bayesian correlated *t*-test | Corani, G., & Benavoli, A. (2015). A Bayesian approach for comparing cross-validated algorithms on multiple data sets. *Machine Learning*, 100, 285-304. |
| Bayesian analysis of classifier comparisons, ROPE | Benavoli, A., Corani, G., Demšar, J., & Zaffalon, M. (2017). Time for a change: a tutorial for comparing multiple classifiers through Bayesian analysis. *JMLR*, 18(77), 1-36. |
| Nested cross-validation | Cawley, G. C., & Talbot, N. L. C. (2010). On over-fitting in model selection and subsequent selection bias in performance evaluation. *JMLR*, 11, 2079-2107. |
| Expected calibration error | Guo, C., Pleiss, G., Sun, Y., & Weinberger, K. Q. (2017). On calibration of modern neural networks. *ICML*. |
| Brier score decomposition | Murphy, A. H. (1973). A new vector partition of the probability score. *Journal of Applied Meteorology*, 12(4), 595-600. |
| Bias-variance decomposition | Domingos, P. (2000). A unified bias-variance decomposition and its applications. *ICML*. |

The `CITATION.cff` file lists the first, third and fifth of these as
references so that citation managers pick them up automatically.
